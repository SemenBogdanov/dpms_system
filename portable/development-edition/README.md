# DPMS Development Edition

Автономная версия «простосделал.рф» только с разделом **«Развитие»** и локальной базой SQLite.

Внутри доступны три рабочих сценария:

1. «Пройти опрос».
2. «Индивидуальный план развития».
3. «Конструктор компетенций».

Каталог зафиксирован по production-релизу `2def4d6d1435d643041d6f3edb139f4169684485`: 6 компетенций, 84 вопроса, 420 вариантов ответа и 24 интерпретации. Production-пользователи, назначения, ответы, результаты и планы развития в пакет не входят.

## Запуск на Ubuntu 24.04

Скопируйте распакованную папку с флешки на локальный диск и выполните:

```bash
sudo ./install-ubuntu.sh
sudo ./start.sh
```

Если Docker Engine с Compose уже установлен, нужна только вторая команда. После проверки готовности откройте:

```text
http://localhost:8787
```

При первом входе система попросит создать локального администратора. Предустановленных логинов и паролей нет.

На macOS с установленным Docker Desktop запуск выполняется командой:

```bash
./start.sh
```

## Управление

```bash
./status.sh
./backup.sh
./stop.sh
./restore.sh runtime/data/backups/development-YYYYMMDDTHHMMSSZ.sqlite3
```

Рабочая база находится в `runtime/data/development.sqlite3`. Резервные копии создаются в `runtime/data/backups/`. Остановка или пересборка контейнера не удаляет данные.

Перед переносом на флешку остановите систему и сохраните свежую резервную копию. Не удаляйте каталог `runtime/data`, если в системе уже есть результаты сотрудников.

## Настройка адреса

По умолчанию приложение доступно только на самом компьютере. Другой порт:

```bash
DPMS_PORT=8790 ./start.sh
```

Доступ из локальной сети включается явно:

```bash
DPMS_BIND_ADDRESS=0.0.0.0 ./start.sh
```

Перед сетевым доступом ограничьте порт межсетевым экраном доверенной подсетью. Встроенный пакет не настраивает TLS и публичную публикацию.

## Проверка поставки

```bash
./verify.sh
```

Проверка сверяет контрольную сумму каталога и запрещает поля пользователей, назначений, ответов и результатов в seed-файле.

## Сборка архива

```bash
./package.sh
```

Готовый source-архив и его SHA-256 появятся в `archives/`. Для первой сборки Docker-образа требуется интернет. Если рядом находится подходящий готовый образ `images/dpms-development-edition-amd64.tar.gz` или `images/dpms-development-edition-arm64.tar.gz`, `start.sh` загрузит его без пересборки приложения.

Готовый образ для типового Ubuntu-компьютера `x86_64` и полный USB-архив создаются так:

```bash
./build-image-archive.sh amd64
./package.sh
```

Для ARM-сервера или Apple Silicon укажите `arm64`. Если готовый образ присутствует в `images/`, `package.sh` дополнительно создаст соответствующий `*-usb.tar.gz`.
