## Сценарий приёмки

1. **1:** открыть прежний адрес http://localhost:55177/graphs и обновить страницу.
2. **2.2:** выбрать инструмент стикера, нажать на холст, ввести имя, нажать Tab.
   Следующий стикер должен сразу принимать ввод. Esc завершает цепочку.
3. **2.4–2.6:** у прямоугольника отключить автоматический размер. Видны пять
   точек на каждой стороне; обычное перетаскивание меняет размер. Shift-drag
   из точки рисует предварительную стрелку, порт соседнего элемента подсвечивается.
   Отпустить: наконечник приходит носом к выбранной границе.
4. **2.7:** добавить список из семи строк, отключить автоматический размер,
   растянуть вниз: все семь строк видны. После reload высота и строки сохраняются.
5. **2.8:** колесо увеличивает/уменьшает масштаб. Слева `Представление` →
   `Инверсия колеса` меняет направление. Space + drag по-прежнему перемещает холст.
6. **2.12:** меню файла → `Импорт JSON` → `Выбрать JSON` → `Формат данных`.
   Проверить пять режимов, предпросмотр и явное `Создать граф локально`.
   Для произвольного JSON выбрать `Дерево JSON · объекты и массивы`.
   Для таблицы/связей настроить поля при необходимости. Отмена не меняет граф.
   Родной DPMS-граф и произвольные данные — разные режимы, а не один формат.
7. **2.3:** открыть мастер иерархий → `База знаний`: открывается статья
   `Графы: мастер иерархий и работа со структурой`, а не первый материал списка.
8. **3.1:** сменить тему DPMS на dark/rose/light: граф следует за ней, отдельной
   кнопки темы нет, текущая работа не сбрасывается.
9. **2.1, 2.9–2.11:** проверить галочку линзы, выделение рамкой, дочерний/соседний
   хоткеи, reload локальной копии. Отправка в систему — только стрелкой в списке графов.
