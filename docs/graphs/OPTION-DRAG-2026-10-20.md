# Копирование Option/Alt с перетаскиванием

Запрос пользователя от20.10.2026: «Хочу чтоб при зажатой клавише options элемент
копировался как в figma». Расширение взаимодействий графа рядом с пунктом3.2
исходного чек-листа; принятые жесты2.8 сохраняются.

Локальная приёмка: **http://localhost:55177/graphs**. Production deploy не разрешён
этим запросом. Backend, миграции, существующие пользовательские графы и БД
не изменяются.

## Контракт

- Option на Mac или Alt на Windows/Linux + перетаскивание создаёт копию.
  Простое нажатие клавиши или Alt+клик без движения ничего не дублирует.
- Копируется один узел, текущее выделение или группа при перетаскивании заголовка.
  Порог начала жеста:3 экранных пикселя.
- Оригиналы остаются на месте. Копии получают новые ID; сохраняются текст,
  свойства, размеры, цвет, sourceRef, содержимое списков и признак закрепления.
- У выделения копируются только внутренние связи, включая порты, подписи,
  routing и ручные точки маршрутов. Внешние связи не размножаются.
  Группа дублируется только при перетаскивании её заголовка; выбор отдельных
  узлов не изменяет состав исходных групп.
- Option можно нажать уже во время движения: оригинал вернётся на место,
  под указателем появится копия. Отпускание Option до завершения жеста возвращает
  перемещение оригинала. Повторное нажатие использует те же ID копий.
- Shift после начала жеста фиксирует ось; исходный Shift+перетаскивание для
  соединения узлов и Space для перемещения холста сохраняются.
- Во время Option-копирования привязки временно отключены, как ранее при
  Alt-перетаскивании. Для обычного перемещения без привязок служат переключатели
  привязки к объектам и сетке.
- Копии перемещаются целиком, включая внутренние ручные маршруты. Для каждого
  представления новые позиции вычисляются от позиций соответствующих оригиналов.
  Координаты оригиналов и параметры представлений сохраняются.
- До отпускания мыши изменения не сохраняются. Escape, pointercancel,
  потеря захвата указателя или уход со страницы отменяют предварительные изменения.
  Выделение возвращается к оригиналам.
- Весь жест занимает один шаг Undo/Redo. Ошибка сохранения откатывает копии.
  Действуют лимиты1500 узлов,3000 связей,300 групп,5МБ и координат ±100000.

## Ручная Приёмка

1. Открыть `/graphs`, выбрать узел и перетащить его с зажатой Option.
   Отпустить мышь до клавиши: оригинал на месте, новая копия выделена.
2. Undo удаляет только копию; Redo возвращает её с теми же свойствами.
3. Выделить два связанных узла и повторить: внутренняя связь скопирована,
   связь с третьим узлом не дублируется.
4. Проверить заголовок раскрытой и свёрнутой группы.
5. Начать обычное перемещение, нажать и отпустить Option без движения указателя:
   режим меняется сразу. Escape возвращает исходное состояние.
6. Перезагрузить страницу и переключить представление после завершённого
   копирования. Проверить прежние два пальца/щипок на MacBook (пункт2.8).

пользовательские записи и cloud-публикация в проверках не создаются.
