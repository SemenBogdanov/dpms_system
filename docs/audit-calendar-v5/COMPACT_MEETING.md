# Компактный План Встречи

15.09.2026. Дополнение локального кандидата `feature/calendar-compact-layout`
по двум скриншотам пользователя. Backend, БД и production не менялись.

## Компоновка

- Дата, начало и длительность заменены короткой строкой выбранного слота.
  Карандаш раскрывает прежние поля, повторное нажатие сворачивает их.
- Группа, активность и докладчик расположены в один ряд на desktop.
  На телефоне поля расположены вертикально, touch controls не меньше 44px.
- Недоступные группы и замечания остались под общим рядом. Состав А/Т
  отображается после выбора группы, без пустых повторяющихся подписей.
- Необязательное основание убрано из создания нового плана/черновика.
  Для редакции, отмены, факта и уведомления обязательная причина сохранена.
  Уже введённая причина не исчезает при возвращении статуса «Запланировано».
- Статус и сохранение остались. Фактическое время при фиксации факта
  по-прежнему редактируется открыто.

## Сохранность

Сворачивание времени не размонтирует командную форму: введённые поля,
исходная CAS-версия и UUID повторного запроса сохраняются. Ручная валидация
проверяет скрытые дату, начало и длительность, включая черновик; некорректное
время раскрывается для исправления и не отправляется на сервер.
Проверка доступности групп, prefill и разграничение прав не изменены.

## Проверки

- Полный Playwright: 325 PASS, 1 прежний WebKit pointer-drag SKIP.
- 14 новых проверок на Chromium/WebKit: геометрия, создание, время,
  скрытые невалидные значения, причины и факты. 60 снимков новой формы,
  ширины 1920/1440/1024/390/320, темы light/dark/rose.
- Lint и access/navigation/mobile smoke PASS; 3 прежних предупреждения
  вне scope. Docker frontend build PASS.
- Native Docker: Chromium/WebKit PASS, 45 снимков графика/выбора/prefill,
  0 записей календаря. Evidence:
  `artifacts/audit-calendar/native-windows/2026-09-15T11-42-18-064Z/`.
- Независимый read-only critic по финальному diff: GO, P1/P2 не обнаружены.
- Backend unit-тесты повторно не запускались: сервер не менялся.
- Снимки для просмотра: `artifacts/audit-calendar/compact-meeting/desktop.png`
  и `mobile.png`. Визуально проверены также native prefill и тема rose.

## Приёмка

1. Открыть `http://localhost:5177/audit-calendar?view=graph` и выбрать пустую ячейку.
2. Проверить короткую строку времени и ряд «Группа / Активность / Докладчик».
3. Выбрать группу и докладчика, заполнить активность. Основания быть не должно.
4. Карандашом изменить время, свернуть поля: введённые значения остаются.
5. Сохранить тестовую встречу и проверить её в графике. В редакции существующей
   встречи причина изменения остаётся обязательной.

Пересобран только существующий frontend на 5177, backend остаётся на 8004.
Предыдущие локальные изменения компактности и доступности сохранены.
Commit/release/deploy требуют отдельного решения. Откат frontend без отката БД.
