## Critic Review

Независимый критик рассмотрел права, блокировки, конкуренцию, историю, импорт и UI.
Замечания исправлены и покрыты регрессиями:

1. Новый draft из JSON не может назначать observer докладчиком.
2. Редактирование существующей встречи без duration не сбрасывает её на 30 минут: HTTP 422.
3. Серверное время обновляется после ожидания scope/user locks; проверка перехода через полночь PASS.
4. DB CHECK явно требует timestamps для открытой и завершенной заявки.
5. Восстановление исторического факта не ограничено текущей ролью докладчика;
   действующий допуск обязателен. Неактивный сотрудник остается видимым, но недоступен
   для выбора. Исходное значение не подменяется автоматически.

Main integration review также исправил кнопку замка у обычного сотрудника и согласовал
выбранную длительность окна между сводкой и уведомлением. Important projection и защита
от повторной доставки проверены по реальным записям БД, а не только по whitelist.
Critic GO по исходникам; native UI gate закрыт отдельно основной сессией.

## Browser Evidence И Ограничения

Новый runner: `frontend/scripts/verify-calendar-controls-native.mjs`.
Он допускает только loopback 5177 и синтетические учетные записи. Последовательность:
helper lock → employee request → helper approve → employee edit → helper close/relock.
Проверяются серверные timestamps, точный payload без подставленного времени, закрытые
контролы обеих ролей, сохранение причины после Escape/клика вне формы, admin без
участия в контуре, возврат из архива. История теста остается в кандидатной БД.

Последний завершенный прогон: `artifacts/audit-calendar/native-controls/2026-09-14T07-42-40-211Z/`:
24 PASS, 96 скриншотов, Chromium/WebKit, 1440/390, light/dark/rose, scope восстановлен.
Проверка выполнена после последней пересборки frontend. Основная сессия просмотрела
мобильную заявку с тремя датами и закрытую доступность; runner ожидает завершения
адаптивного закрытия бокового меню перед снимком, чтобы не захватывать переходный кадр.
Финальная БД: schema091, `archived=false`, шесть синтетических заявок закрыты,
активных заявок нет. Backend health и frontend HTTP 200, workspace invariants PASS.

Во время отладки обнаружены и исправлены нестабильная связь подписи с textarea причины
и зависание повторной browser-навигации runner в админку. Runner теперь обновляет
панель штатной кнопкой и отдельно проверяет снятие запрета навигации после сохранения.
После прерванного локального archive-теста контур восстановлен; последующие полные
прогоны подтверждают archive/restore через UI. Незакрытая заявка не удаляется для очистки.

Остаточный дефект вне scope: общая страница `AdminUsersPage` шире экрана 390 px.
Панель календаря укладывается в viewport, кнопки архива доступны; runner явно отмечает
внешний overflow как RESIDUAL, а не скрывает его. Общая мобильная админка требует
отдельной доработки. На страницах самого календаря горизонтального overflow нет.
