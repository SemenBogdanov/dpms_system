# Компактная Вёрстка Календаря

Локальный slice поверх production74b51f5. Задача: согласованный пользовательский
макет, период в левой колонке над навигацией, группа/участник/докладчик/длительность
и одна кнопка обновления в верхней полосе вместе с KPI. Больше места графику.

Период, URL-фильтры, поиск активности, KPI, роли, план/факт, модалки и замки
сохраняются. Первичная загрузка и смена фильтров загружают соответствующий набор;
focus/visibility/click по графику сами по себе не обновляют данные. Обновление
кнопкой перечитывает график и окна. Открытие конкретного окна заново проверяет
состав на сервере; сохранение встречи сохраняет окончательный CAS/booking guard.
Глобальная проверка доступа по focus не отключается.

Точки изменения: AuditCalendarPage, CalendarGraph, CalendarMeetingWindows,
calendar CSS и scoped browser regression. Backend domain и production не меняются.
Мобильный период сворачивается, навигация и фильтры остаются доступны с touch44px.

Эталон: artifacts/audit-calendar/compact/reference.png, исходный скриншот пользователя.
Проверки: Chromium/WebKit,1920/1440/1024/390/320,light/dark/rose, stale/revoke,
modals, refresh request counts, period/filter persistence, build/lint/navigation.
Визуальный review: одна сгруппированная корректировка и подтверждающий проход.

## Результат 15.09.2026

- Кандидат `feature/calendar-compact-layout`, baseline `74b51f527088`.
- Период перенесен над локальной навигацией. Группа, участник, докладчик,
  длительность, поиск и общее обновление собраны в верхней полосе с KPI.
- Убраны оба calendar-specific триггера: focus/visibility refresh и visibility
  gate запроса окон. Глобальный профильный access-refresh не менялся.
- Native проверка: focus не запрашивает state/windows; явное обновление дает
  ровно один state и один batch. Открытие окна проверяет актуальный состав.
- Найденная регрессия draft guard исправлена: все кнопки/поля нового блока
  периода заблокированы при несохраненной доступности и выполняющейся записи.
- Header измеряет собственную ширину, а не только viewport. При открытом общем
  меню на 1440px фильтры переходят во вторую строку без сжатия надписей.
  Container ограничен header: фиксированные модалки остаются вне него.
- На телефоне период свернут, локальная навигация доступна над графиком;
  элементы управления не меньше44px, поля16px. Поиск сохранен под лупой.

## Проверка Пользователем

1. Открыть `http://localhost:5177/audit-calendar?view=graph`.
2. Проверить период слева; на широком экране фильтры и KPI находятся вверху.
3. Переключить окно браузера и вернуться: пересчета слотов быть не должно.
4. Нажать круговую стрелку справа от фильтров: график и окна обновляются.
5. Выбрать зеленое/желтое окно: увидеть состав; проверить предзаполнение
   встречи без сохранения. Закрыть и явно удалить только этот черновик.
6. Проверить нужный период, группу/участника и тему; на узком экране раскрыть
   период над горизонтальной локальной навигацией.

Production не изменялся. Локальные данные не импортировались и не сбрасывались.
Для возврата к предыдущему UI достаточно прежнего frontend из `74b51f527088`;
откат БД не нужен. Release/deploy только после отдельного согласования.
