# Web Push для iPhone

DPMS отправляет системные уведомления установленному на экран «Домой» веб-приложению iOS 16.4+. Источник событий: адресные обращения и whitelist вкладки «Важное» в разделе «Сообщения». Payload содержит только общую формулировку и ссылку внутри DPMS; тексты писем, заметок, задач и договоров не отправляются.

## Конфигурация production

- В защищённой конфигурации backend и `web-push-worker` задать один и тот же `DPMS_WEB_PUSH_PRIVATE_KEY`: неизменяемый base64url-кодированный raw P-256 private key длиной 32 байта. Не помещать ключ в git, PersonalOS или URL.
- Задать `DPMS_WEB_PUSH_SUBJECT`: адрес `mailto:` администратора сервиса либо HTTPS-origin сайта без пути. Завершающий `/` нормализуется приложением. Оба значения должны попасть в production env-файл, на который ссылается `DPMS_ENV_FILE`.
- Разрешить исходящее HTTPS-соединение worker к `*.push.apple.com:443`. Входящий порт для Web Push не требуется.
- Сохранить VAPID-ключ в резервном контуре: при его потере/замене существующие подписки потребуется пересоздать на iPhone.

Release preflight проверяет наличие корректных настроек **до** миграции `095_web_push`. Promote запускает `web-push-worker`, healthcheck проверяет его работу и конфигурацию. Rollback возвращает старую версию приложения и останавливает новый worker, если его нет в предыдущем Compose; БД при этом автоматически не откатывается.

## Проверка на iPhone

1. Открыть HTTPS-сайт DPMS, добавить на экран «Домой» и запустить именно с ярлыка. Если старый ярлык продолжает открывать браузерную вкладку, удалить его и добавить заново.
2. В «Сообщениях» нажать «Включить уведомления» и разрешить их в системном диалоге iOS. Без этого нажатия DPMS не запрашивает разрешение.
3. С другой учётной записи отправить личное письмо. Свернуть DPMS: должна появиться нейтральная системная нотификация, открывающая нужную переписку.
4. Создать событие из вкладки «Важное» и проверить переход в неё. Прочтённое до отправки событие не должно порождать запоздалый push.
5. Нажать «Отключить» и проверить, что новые события остаются в DPMS, но больше не приходят на устройство.

При отказе в разрешении iOS его меняют в настройках уведомлений устройства. Доставка Web Push зависит от APNs, сети и режимов «Фокусирование»; запись в DPMS остаётся источником истины.
